# PLC 데이터 수집기 v0.2 (웹 화면 포함)

PLC·ADAM 같은 장치에서 값을 읽어 CSV로 저장하는 도구입니다.
**읽을 변수, 수집 주기, 이벤트 조건을 웹 화면에서 바꿀 수 있어 코드를 고치지 않아도 됩니다.**
Python 3.8 이상만 있으면 되고 추가 설치는 필요 없습니다. (인터넷 연결도 필요 없습니다)

## 1. 실행

- Windows: `start.bat` 더블클릭
- Mac/Linux: `./start.sh`  (또는 `python3 server.py`)

브라우저가 자동으로 열립니다. 열리지 않으면 `http://127.0.0.1:8765` 로 접속하세요.
종료는 실행 창에서 Ctrl+C 입니다.

처음 실행하면 **데모 설정**(가상 PLC 1대, ADAM-6017, FC-5000)이 들어 있어 실제 장치 없이 바로 체험할 수 있습니다.
대시보드의 **[데모 장치 켜기]** → 오른쪽 위 **[수집 시작]** 순서로 눌러 보세요.

## 2. 화면 구성

| 화면 | 하는 일 |
|---|---|
| 대시보드 | 현재 값(신호 램프·측정값 추세), 수집 작업 진행 상황, 최근 기록 |
| 장치 | PLC/ADAM의 IP·포트·국번 등록, **연결 테스트** |
| 변수 | 읽을 값에 이름·주소·타입·단위 지정, **값 읽어보기**, 엑셀·CSV 가져오기/내보내기 |
| 수집 작업 | 주기 / 이벤트 / 사이클 방식으로 무엇을 언제 저장할지 설정 |
| 결과 파일 | 저장된 CSV 미리보기·다운로드·삭제 |
| 주소 탐색 | 주소 범위를 그대로 읽어 값·32비트 해석 확인 (주소·워드순서 찾기) |

수집 시작은 화면 오른쪽 위 버튼입니다. 시작할 때 **이번에만 수집 주기 바꾸기**, **수집 시간**을 정할 수 있습니다.

## 3. 사용 순서 (실제 장비)

1. **장치** 에서 IP 주소·포트(보통 502)를 입력하고 연결 테스트
2. **변수** 에서 읽을 값을 등록 (엑셀 표를 그대로 붙여넣어도 됨). 저장 전에 **값 읽어보기** 로 확인
3. **수집 작업** 에서 방식을 골라 작업 생성
   - 주기 수집: 정해진 간격마다 저장
   - 이벤트 수집: 신호가 켜지는 순간의 값을 저장
   - 사이클 수집: 시작~종료 신호로 한 사이클을 한 줄로 묶어 저장 (적산 유량 차이 계산 포함)
4. 오른쪽 위 **수집 시작**

값이 이상하면 **주소 탐색** 에서 원시값을 보며 주소 오프셋(±1)과 워드 순서를 맞춥니다.

주의: 데모 설정의 ADAM 주소/스케일은 **형식 예시**입니다. 실제 ADAM-6017 레지스터 위치와 값 범위, LS PLC의 Modbus 주소 매핑 설정은 각 장비 매뉴얼과 XG5000 설정으로 확인해야 합니다.

## 4. 데이터 위치

모든 데이터는 `data/` 폴더에 저장됩니다.

| 경로 | 내용 |
|---|---|
| `data/config.json` | 장치·변수·작업 설정 (화면에서 저장할 때마다 갱신) |
| `data/backups/` | 설정을 저장할 때마다 이전 설정 자동 백업 (최근 30개) |
| `data/output/` | 수집 결과 CSV |

설정을 완전히 처음으로 되돌리려면 서버를 끄고 `data/config.json` 을 삭제한 뒤 다시 실행하세요.

## 5. 다른 PC에서 접속하기 (선택)

기본은 **이 PC에서만** 접속됩니다. 다른 PC에서 보려면 비밀번호를 걸어 실행하세요.

```
python server.py --host 0.0.0.0 --password 원하는비밀번호
```

다른 PC 브라우저에서 `http://서버PC의IP:8765` 로 접속하면 비밀번호를 묻습니다.
설비와 연결된 프로그램이므로 비밀번호 없이 외부 접속을 허용하지 마세요.
포트 변경: `--port 9000`, 브라우저 자동 실행 끄기: `--no-browser`

## 6. 명령줄 도구 (개발자용)

화면 없이도 쓸 수 있습니다. 설정 파일 기본값은 `config.example.json` 이고 `-c data/config.json` 으로 화면에서 만든 설정을 쓸 수 있습니다.

```
python collector.py test -c data/config.json
python collector.py run  -c data/config.json --jobs monitor --period-ms 500 --duration 60
python collector.py scan -c data/config.json --device plc1 --area holding --start 0 --count 10
python collector.py sim                 # 가상 장치만 실행
```

## 7. 한계와 다음 단계

- 프로토콜은 **Modbus TCP(읽기 전용)** 만 지원합니다. LS XGT 전용 프로토콜은 `engine.py` 의 `make_client()` 에 driver를 추가하고 화면의 프로토콜 목록에 항목을 여는 방식으로 확장합니다.
- 이벤트는 폴링으로 감지합니다. 신호가 **신호 확인 간격**보다 짧게 켜졌다 꺼지면 놓칠 수 있습니다.
- 결과 저장은 CSV만 지원합니다. (PostgreSQL/Parquet은 `CsvSink` 와 같은 형태로 추가 가능)
- 사이클 번호(Cycle ID)는 수집을 시작할 때마다 1부터 다시 시작합니다.
- 서버 프로그램이 꺼지면 수집도 멈춥니다. 상시 운전이 필요하면 PC 시작 시 자동 실행(작업 스케줄러 등) 구성이 필요합니다.
- 수집 중에 설정을 바꾸면 **다음 수집부터** 반영됩니다.

## 8. 파일 구성

| 파일 | 역할 |
|---|---|
| `server.py` | 웹 서버 (화면 제공 + API) |
| `web/` | 화면 (index.html, app.css, ui.js, pages1.js, pages2.js, main.js) |
| `engine.py` | 설정 검증, 일괄 읽기, interval/event/cycle 작업, 실행 관리 |
| `tagcodec.py` | 주소 해석, 타입 변환, 스케일링 |
| `modbus_tcp.py` | Modbus TCP 클라이언트 + 가상 서버 |
| `simulator.py` | 데모 장치 값 생성 |
| `collector.py` | 명령줄 도구 |
| `config.example.json` | 데모 설정 (처음 실행 시 `data/config.json` 으로 복사됨) |
| `start.bat` / `start.sh` | 실행 스크립트 |
